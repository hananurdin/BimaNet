# Galeri Foto dengan Lightbox

Ini adalah proyek galeri foto berbasis HTML dan CSS yang menggunakan **Lightbox2** untuk menampilkan gambar dalam tampilan pop-up yang elegan. Cocok untuk portofolio pribadi, dokumentasi event, atau koleksi foto.

## 🎯 Fitur

- Galeri foto responsif
- Tampilan lightbox saat gambar diklik
- Navigasi next/prev antar gambar
- Efek animasi saat transisi
- Mudah di-deploy ke GitHub Pages

## 🚀 Demo

Lihat galeri secara langsung di:
[https://hananurdin.github.io/BimaNet/](https://hananurdin.github.io/BimaNet/)  
> Ganti `username` dengan nama pengguna GitHub kamu.

## 🛠️ Cara Pakai

1. **Clone repositori ini** atau unduh secara manual:
   ```bash
   git clone https://github.com/hananurdin/BimaNet.git
   ```

2. **Struktur folder**:
   ```
   galeri-foto/
   ├── index.html
   ├── /img/
   │   └── foto1.jpg, foto2.jpg, ...
   └── README.md
   ```

3. **Ganti gambar** di folder `/img/` dengan gambar milikmu.

4. **Push ke GitHub**, lalu aktifkan GitHub Pages:
   - Buka **Settings → Pages**
   - Pilih `main` branch dan folder root (`/`)
   - Klik **Save**

5. Buka link GitHub Pages: `https://hananurdin.github.io/BimaNet/`

## 📦 Teknologi
